# Модель данных: пилот Томаса—Килманна

Дата: 2026-10-02. Ниже описаны существующие файлы и планируемые связи; базы данных пока нет.

| Объект | Поля пилота | Связи |
|---|---|---|
| Версия формы | `id`, `version`, `method_id`, `status`, `provenance` | Содержит 30 пунктов |
| Пункт | `id`, `number`, `options` | Две альтернативы A/B |
| Альтернатива | `value`, `label`, `text`, `source_text` | Текст отделен от расчетного ключа |
| Версия ключа | `id`, `key_version`, `items`, `type`, `scales`, `verification` | Текущая 1.0.0 хранится отдельным JSON; legacy сохраняется |
| Вход расчета | `contract_version`, `method_version_id`, `handler_version`, `responses` | Пункт связывается по ID, не по позиции массива |
| Результат | `status`, `validation_state`, `quality`, `measures`, `warnings`, `calculation` | Пять сырых показателей и digest ключа |

Будущая запись прохождения должна хранить собственный ID и ссылки на версии формы/методики/обработчика. Исследование, группа, этап и участник связываются с прохождением отдельными идентификаторами. Создание нового этапа не копирует прежние ответы.

Форма привязана к `tki_ru_30_pairs@1.0.0`. Прежний `legacy-5.5.8-draft` воспроизводится по явному запросу со старой версией обработчика. Исторические результаты автоматически не обновляются; новый расчет сохраняется с новым идентификатором версии и digest.

Точные таблицы, типы ID, миграции и права доступа будут определены отдельной задачей после выбора стека. Выбор половой категории не требуется для отображения общего бланка и не влияет на текущий расчет пяти сырых шкал.

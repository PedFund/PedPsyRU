Проверки: Node.js >=22.17.1, команда `npm test`. Внешние пакеты не требуются. Встроенный node:sqlite экспериментальный в проверенной версии; выбран только для учебного контура.

Ключ [1.0.0](methods/tki/keys/1.0.0.json) исправлен по подтверждению владельца: **21A — приспособление, 21B — сотрудничество**. Все 60 альтернатив совпадают с контрольным ключом, каждая шкала содержит 12 пунктов. Новые вызовы `scoreTki` используют версию 1.0.0, старый ошибочный ключ удален, переключения на него нет. Полная инструкция и утверждение методики остаются отдельной задачей.

Браузерный стенд: `npm start`, затем `http://127.0.0.1:4173`. Каждая пара A/B — отдельный слайд. `/` — несохраняемая демонстрация с техническим просмотром сырых баллов; обновление очищает ее. `/access` → назначение → `/take` — отдельное учебное прохождение: ответы и текущий слайд автоматически сохраняются в SQLite и восстанавливаются после входа. Состояние записи видно; конфликт вкладок не перезаписывает чужое обновление. Полный сохраненный протокол завершается после подтверждения: один неизменяемый результат с пятью raw шкалами, без интерпретаций; reload/вход возвращают тот же результат. Только вымышленные данные; реализация в PR #7, не main.

`npm test`: **134 успешных** (15 completion + 22 draft + 21 staff + 23 participant + 22 storage + 31 прежний). `/admin` — обе административные роли, просмотр/контроль статусов и скачивание первичных ответов **всех исследований** в JSON, с аудитом. Администратор не обрабатывает/дополняет методики; суперадминистратор — менеджер исследователей и методик. Управление исследователями/редактор методик пока отдельные будущие задачи.

Индивидуальные вымышленные credentials выдаются только в своем интерактивном терминале: `npm run auth:issue -- 1 DEMO-001`; для администратора `npm run staff:issue -- administrator PLATFORM-ADMIN`, для суперадминистратора `npm run staff:issue -- superadministrator PLATFORM-SUPERADMIN`. Универсального пароля и auto accounts нет, секрет показывается один раз. Порядок reset/revoke и ограничения — ADMIN_VALIDATION.md. Следующая граница — разрешенная интеграция PR #1–#7 и тестирование общего дерева; автоматически не объединяются. Реального набора/публичного размещения нет.

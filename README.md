Проверки: Node.js >=22.17.1, команда `npm test`. Внешние пакеты не требуются. Встроенный node:sqlite экспериментальный в проверенной версии; выбран только для учебного контура.

Ключ [1.0.0](methods/tki/keys/1.0.0.json) исправлен по подтверждению владельца: **21A — приспособление, 21B — сотрудничество**. Все 60 альтернатив совпадают с контрольным ключом, каждая шкала содержит 12 пунктов. Новые вызовы `scoreTki` используют версию 1.0.0, старый ошибочный ключ удален, переключения на него нет. Полная инструкция и утверждение методики остаются отдельной задачей.

Браузерный стенд готов: `npm start`, затем `http://127.0.0.1:4173`. Каждая пара A/B — отдельный слайд; «Назад»/«Далее» сохраняют выбор, виден прогресс и номер вопроса. Есть подсветка пропусков, открытие нужного слайда и передача полных ответов существующему обработчику. Только вымышленные ответы: данные не сохраняются, обновление страницы очищает прохождение. Технический просмотр показывает сырые баллы без интерпретаций.

`npm test`: **97 успешных** (21 staff + 23 participant + 22 storage + 31 прежний). `/access` — вход участника/scoped чтение. `/admin` — обе административные роли, просмотр/контроль статусов и скачивание первичных ответов **всех исследований** в JSON, с аудитом. Администратор не обрабатывает/дополняет методики; суперадминистратор — менеджер исследователей и методик. Управление исследователями/редактор методик пока отдельные будущие задачи.

Индивидуальные вымышленные credentials выдаются только в своем интерактивном терминале: `npm run auth:issue -- 1 DEMO-001`; для администратора `npm run staff:issue -- administrator PLATFORM-ADMIN`, для суперадминистратора `npm run staff:issue -- superadministrator PLATFORM-SUPERADMIN`. Универсального пароля и auto accounts нет, секрет показывается один раз. Порядок reset/revoke и ограничения — ADMIN_VALIDATION.md. Следующий 01д.4 — сохранение черновика/слайда и восстановление; новая форма пока не сохраняется. Реального набора/публичного размещения нет.

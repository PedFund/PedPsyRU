# PedPsyRU
Информационно-аналитическая платформа организации, проведения и анализа психолого-педагогических исследований

Первый небольшой этап — бланк и вычислительный контракт Томаса—Килманна. Общий бланк для мужчин и женщин создан из текста владельца проекта; грамматические формы отвечающего объединены через `/`.

- [Бланк для просмотра](methods/tki/BLANK.md).
- [JSON: 30 пар, 60 альтернатив и исходные формулировки](methods/tki/form.json).
- [Черновой вызов обработчика](core/README.md).
- [Журнал проверки методики](METHOD_VALIDATION.md).
- [Текущий статус](STATUS.md) и [очередность задач](BACKLOG.md).

Проверки: Node.js 22+, команда `npm test`. Установка внешних пакетов для пилотных тестов не требуется.

Текст формы получен, проверка версии методики продолжается. В legacy-ключе 21A отнесен к избеганию, в научной публикации — к приспособлению. Пилот сохраняет прежние формулы и возвращает `usable_for_aggregation: false` до принятия решения по версии ключа.

Форма предъявления, хранение ответов и платформа исследований будут создаваться следующими отдельными задачами. В этой версии есть Markdown-бланк, данные формы и тестируемый вычислитель; браузерного прохождения и базы данных пока нет.

Проверки: Node.js >=22.17.1, команда `npm test`. Внешние пакеты не требуются. Встроенный node:sqlite экспериментальный в проверенной версии; выбран только для учебного контура.

Ключ [1.0.0](methods/tki/keys/1.0.0.json) исправлен по подтверждению владельца: **21A — приспособление, 21B — сотрудничество**. Все 60 альтернатив совпадают с контрольным ключом, каждая шкала содержит 12 пунктов. Новые вызовы `scoreTki` используют версию 1.0.0, старый ошибочный ключ удален, переключения на него нет. Полная инструкция и утверждение методики остаются отдельной задачей.

Браузерный стенд готов: `npm start`, затем `http://127.0.0.1:4173`. Каждая пара A/B — отдельный слайд; «Назад»/«Далее» сохраняют выбор, виден прогресс и номер вопроса. Есть подсветка пропусков, открытие нужного слайда и передача полных ответов существующему обработчику. Только вымышленные ответы: данные не сохраняются, обновление страницы очищает прохождение. Технический просмотр показывает сырые баллы без интерпретаций.

`npm test`: **76 успешных** (23 доступа + 22 хранения + 31 прежний). 01д.3а добавила вход участника/scoped чтение и `/access`. Индивидуальные вымышленные credentials выдаются только локальной интерактивной командой `npm run auth:issue -- 1 DEMO-001`; универсального пароля нет. Форма пока не сохраняется. По уточнению владельца оба административных уровня смогут смотреть и скачивать ответы — следующий 01д.3б; роли/экспорт еще не реализованы. Затем 01д.4 — черновик/слайд. Реального набора/публичного размещения нет.

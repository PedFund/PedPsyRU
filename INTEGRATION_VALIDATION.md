## Почему код оставался в ветках

Шаги 01а–01е публиковались зависимой цепочкой PR #1–#7; до приемки все они оставались open/unmerged. Последняя ветка содержит весь пилот, не семь отдельных программ. GitHub по умолчанию показывает main, где до интеграции были только AGENTS.md, ROADMAP.md и начальный README. Цепочку следовало раньше вывести на интеграционную приемку; создание следующего звена не является заменой интеграции.

AGENTS.md разрешает автономную техническую работу, но прямо требует отдельного разрешения владельца для merge в main. Предыдущее указание также запрещало автоматически объединять все открытые PR. Сначала выполнена подготовка без изменения main; затем отдельное прямое разрешение получено и применено только к итоговому PR #7.

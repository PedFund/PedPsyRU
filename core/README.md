# Пилот вычислительного контракта: Томас—Килманн

Адаптер `tki-contract.js` вызывает существующую `scoreComplete` с единственным поддерживаемым ключом 1.0.0 и проверяет его SHA-256. Для новых вызовов экспортируются версии `tki_ru_30_pairs@1.0.0` и `tki-contract-0.3.0`. В ключе 1.0.0 ответ 21A перенесен в приспособление, 21B остается в сотрудничестве.

```js
const {scoreTki, CONTRACT_VERSION, METHOD_VERSION_ID, HANDLER_VERSION} = require("./core/tki-contract.js");
const result = scoreTki({
  contract_version: CONTRACT_VERSION,
  method_version_id: METHOD_VERSION_ID,
  handler_version: HANDLER_VERSION,
  responses: Array.from({length: 30}, (_, index) => ({
    item_id: "q" + String(index + 1).padStart(2, "0"),
    value: "B"
  }))
});
```

Ожидаемый результат: пять сырых баллов по 6, `status: "scored"`, `validation_state: "key_verified"`, `usable_for_aggregation: true`, без предупреждений. Разрешение относится к корректно рассчитанным сырым шкалам; полная методика, инструкция и нормативы не утверждаются этим флагом. Пять баллов находятся в диапазоне 0–12, их сумма при полном заполнении равна 30.

Вход: обязательные версии контракта/методики/адаптера и 30 уникальных ответов q01–q30 со значениями строго A/B. Порядок массива свободный. Числовые, кириллические и текстовые ответы требуют отдельного импортного адаптера. Дубликаты, неизвестные пункты и недопустимые значения отклоняются; пропуски дают `incomplete` без баллов.

Выход: версии, статус, состояние проверки, качество, `measures[]` со стабильными кодами и русскими названиями, пустые `classifications[]`, предупреждения с кодами и digest ключа. Нормы и уровни не добавляются. Вызов детерминирован, вход не изменяется. Время расчета, идентификаторы исследования и участника должен записывать вызывающий сервис.

Неизвестная или удаленная версия, а также изменение ключа блокируют вычисление. Версия контракта остается `1.0`. Исполняемые проверки находятся в `tests/tki-contract.test.js`; универсальная JSON Schema для всех методик пока не утверждена.

Старый ошибочный ключ, его версия и маршрут вызова удалены по указанию владельца. В перенесенном каталоге `Methods.byId` записи TKI нет: вызывайте `scoreTki` с указанными версиями. Все назначения находятся только в проверенном JSON. Исходная локальная программа вне нового проекта не изменяется.

Запуск проверок вычислителя: `npm run test:tki`. Проверки бланка: `npm run test:form`. Все проверки пилота в новом репозитории: `npm test`. Это отдельный набор; прежний большой `tests.js` с XLSX-выгрузками в этот пилот не перенесен.

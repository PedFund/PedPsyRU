# Ручной учебный тест новой платформы на ТКИ

Тестировать уже созданную ПедПси, не старую Excel-программу и не новый stand.
Не пересоздавать личный административный аккаунт, пароль или MFA.
Пароль, TOTP, recovery-коды и секреты приглашений не отправлять в чат/GitHub.

1. Войти своей административной учётной записью с обычным подтверждением MFA.
2. Пригласить тестового исследователя через управление исследователями.
   Принять приглашение в отдельном браузерном профиле, создать собственный вход.
3. Создать учебное исследование, КГ/ЭГ, этапT0 и назначить existingTKI.
   Пол/возраст обязательны; дополнительные поля для первого smoke не нужны.
4. Проверить дизайн, активировать исследование, вручную открытьT0 отдельно
   для нужной группы. Создать общую групповую ссылку — это не staff session.
5. Открыть её в отдельном профиле участника. Использовать только вымышленные
   данные и адрес вроде test.participant@example.test, отдельный пароль.
   В synthetic demo подтверждение показывает учебный получатель внутри
   страницы: реального письма нет и владение реальной почтой не доказывается.
6. Заполнить вымышленные паспортные данные, явно принять обязательные согласия;
   дополнительное научное использование остаётся добровольным. ВыбратьT0.
7. Пройти30пар, по одной на каждом слайде. Проверить переходы и перезагрузку
   после нескольких ответов: восстановление должно происходить с сервера.
8. Завершить полный тест. В staff profile посмотреть и скачать ответы/raw
   results; обе staff-роли глобально читают/скачивают, admin не управляет
   методиками/обработкой, researcher не получает индивидуальную диагностику.

Manual end-to-end пока не заявлен пройденным. CI и открытие страницы не заменяют
личную проверку. При ошибке сообщить экран/действие/текст, без секретов.
Тест не разрешает реальный сбор данных, рассылку, Selectel или scientific
publication. Другие методики не задерживают этот сценарий.

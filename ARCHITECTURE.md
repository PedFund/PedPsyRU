HTTP не импортирует pg/storage/adapters, application/ports не выполняют I/O; AST guard проверяет направления/циклы и типовые/runtime imports. Это не полный SAST/научная приемка.

Snapshot переносится offline в пустой target, credentials/sessions создаются заново. Новый API проходит отдельную HTTP/PG приемку; права будущих manager/processing endpoints не считаются реализованными этой основой.

Технический просмотр баллов не является утвержденным индивидуальным отчетом. Этот сервер не определяет производственный стек всей платформы.

## Ограничения

Контракт поддерживает одну методику и только исправленный ключ 1.0.0 с обработчиком `tki-contract-0.3.0`. Ключ 1.0.0 проверен, допустимые полностью заполненные сырые результаты имеют `usable_for_aggregation: true`. Запросы с удаленной или неизвестной версией отклоняются без баллов. Подмена ключа под прежним ID блокируется проверкой digest. Полное утверждение инструкции и методики учитывается отдельно; формальные JSON Schema для универсального контракта и редактора библиотеки предстоит утвердить отдельно.

# Архитектура ПедПси: текущий пилот

Дата: 2026-10-02. Основной репозиторий разработки — `PedFund/PedPsyRU`.

## Принятые границы

- Текст формы: `methods/tki/form.json`. У каждого пункта устойчивый ID q01–q30; варианты имеют коды A/B и русские подписи а/б.
- Бланк: `methods/tki/BLANK.md`; порядок и тексты совпадают с JSON.
- Расчет: `core/tki-contract.js`; вход не зависит от Excel и языка текста вариантов. Новые вызовы используют отдельный ключ `methods/tki/keys/1.0.0.json` (21A — приспособление), а явный выбор старой версии воспроизводит legacy.
- Legacy-вычислитель: `processor.js`, `methods.js`, `methods/builtin.js` перенесены из локальной версии 5.5.8 с сохранением содержимого. Из большого каталога этот пилот использует Томаса—Килманна; другие встроенные обработчики не утверждаются переносом.
- Контрольные примеры: `tests/fixtures/tki-reference.json`; тесты контракта и формы — `tests/`.
- Научная проверка: `METHOD_VALIDATION.md`; успешный расчет не заменяет статус проверки источника.

## Последующие границы

Участник выбирает вариант по коду, а интерфейс отправляет `{item_id, value}`. Текст вопроса и подпись а/б не участвуют в подсчете баллов. Версии текста формы, ключа и вычислителя фиксируются раздельно.

Исследования, произвольные группы, этапы T0/T1/T2 и назначения методик относятся к будущему доменному слою. Хранение, права доступа, согласия и выбор серверного стека еще не реализованы. Развертывание сайта и способ интеграции форм этим пилотом не определяются.

## Ограничения

Новый контракт поддерживает одну методику и две явно выбираемые версии расчета. Ключ 1.0.0 проверен, допустимые полностью заполненные сырые результаты имеют `usable_for_aggregation: true`. Legacy-версия сохраняет прежнее предупреждение и флаг false. Подмена ключа под прежним ID блокируется проверкой digest. Полное утверждение инструкции и методики учитывается отдельно; формальные JSON Schema для универсального контракта и редактора библиотеки предстоит утвердить отдельно.

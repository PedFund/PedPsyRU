# Архитектура ПедПси: текущий пилот

Дата: 2026-10-02. Основной репозиторий разработки — `PedFund/PedPsyRU`.

## Принятые границы

- Текст формы: `methods/tki/form.json`. У каждого пункта устойчивый ID q01–q30; варианты имеют коды A/B и русские подписи а/б.
- Бланк: `methods/tki/BLANK.md`; порядок и тексты совпадают с JSON.
- Расчет: `core/tki-contract.js`; вход не зависит от Excel и языка текста вариантов. Используется только ключ `methods/tki/keys/1.0.0.json` (21A — приспособление, 21B — сотрудничество). Старый ключ и переключение на него удалены.
- Вычислительная формула: существующая `Processor.scoreComplete`, тип `forced`, не переписана. Из копии каталога `methods/builtin.js` удалены ошибочный ключ Томаса—Килманна и его запись описания. TKI вызывается через `scoreTki` с проверенным JSON, не через `Methods.byId`. Другие встроенные обработчики этим пилотом не утверждаются.
- Контрольные примеры: `tests/fixtures/tki-reference.json`; тесты контракта и формы — `tests/`.
- Научная проверка: `METHOD_VALIDATION.md`; успешный расчет не заменяет статус проверки источника.
- Браузерный стенд 01г: `web/index.html`, `styles.css`, `app.js`, `form-model.js`. JSON формы остается единственным источником предъявляемых текстов; передаются только ID и A/B.
- Обязательное требование владельца к предъявлению: каждый вопрос, а в TKI каждая пара A/B, показывается на отдельном слайде. Одновременно виден только один вопрос. Навигация «Назад»/«Далее» сохраняет выбранные ответы, ссылка к пропуску открывает соответствующий слайд; проверка полного протокола доступна на последнем слайде. Порядок вопросов не меняется.
- Локальный транспорт: `web/server.js`, Node.js `http`, только `127.0.0.1`. `GET /api/form` выдает форму и версии; `POST /api/score` вызывает существующий `scoreTki`. Ключ наружу не выдается.
- Ответы и результат браузерного стенда живут в памяти, без записи в базу, файлы, cookies и localStorage. Отдельная тренировочная SQLite-база создана в 01д.2, но web-сервер к ней не подключен. Стенд демонстрационный, технический просмотр баллов не является утвержденным индивидуальным отчетом. Этот сервер не определяет производственный стек всей платформы.

## Последующие границы

01д.1 подготовила схему/матрицу/контракт. 01д.2 создала storage/: SQLite, миграции, пакет TKI, seed и 22 теста. 01д.3а добавила storage/access.js, миграцию 002, web/access-routes.js и /access; сервер использует подготовленный учебный файл только для входа/scoped чтения. Файл не выдается HTTP/Git. Диагностические writes не открыты, вычислитель неизменен. 23 теста доступа, 76 всего — ACCESS_VALIDATION.md. Администратор/суперадминистратор по уточнению владельца смогут смотреть и скачивать ответы; реализации ролей/экспорта еще нет, следующий 01д.3б.

Будущий поток: индивидуальная сессия → проверка области/назначения → сохраненный снимок попытки → существующий `scoreTki` → атомарная фиксация результата. Версии закреплены выпуском; ключ клиенту не выдается. Только demo. Среда: Node.js 22.17.1, экспериментальный node:sqlite / SQLite 3.50.0; выбор только учебный, без облака/production-готовности. Синхронные транзакции и ограничения схемы не заменяют проверку прав и сервис завершения. Детали — storage/README.md.

Участник выбирает вариант по коду, а интерфейс отправляет `{item_id, value}`. Текст вопроса и подпись а/б не участвуют в подсчете баллов. Версии текста формы, ключа и вычислителя фиксируются раздельно.

Таблицы исследований/групп/этапов/назначений созданы, доменный конструктор еще не реализован. Права участника/scoped чтение реализованы, права административных ролей/согласия/production-стек — нет. Развертывание сайта и интеграция форм не определяются этим пилотом.

## Ограничения

Контракт поддерживает одну методику и только исправленный ключ 1.0.0 с обработчиком `tki-contract-0.3.0`. Ключ 1.0.0 проверен, допустимые полностью заполненные сырые результаты имеют `usable_for_aggregation: true`. Запросы с удаленной или неизвестной версией отклоняются без баллов. Подмена ключа под прежним ID блокируется проверкой digest. Полное утверждение инструкции и методики учитывается отдельно; формальные JSON Schema для универсального контракта и редактора библиотеки предстоит утвердить отдельно.

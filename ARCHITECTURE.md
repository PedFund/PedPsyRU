# Архитектура ПедПси: текущий пилот

Дата: 2026-10-02. Основной репозиторий разработки — `PedFund/PedPsyRU`.

## Принятые границы

- Текст формы: `methods/tki/form.json`. У каждого пункта устойчивый ID q01–q30; варианты имеют коды A/B и русские подписи а/б.
- Бланк: `methods/tki/BLANK.md`; порядок и тексты совпадают с JSON.
- Расчет: `core/tki-contract.js`; вход не зависит от Excel и языка текста вариантов. Используется только ключ `methods/tki/keys/1.0.0.json` (21A — приспособление, 21B — сотрудничество). Старый ключ и переключение на него удалены.
- Вычислительная формула: существующая `Processor.scoreComplete`, тип `forced`, не переписана. Из копии каталога `methods/builtin.js` удалены ошибочный ключ Томаса—Килманна и его запись описания. TKI вызывается через `scoreTki` с проверенным JSON, не через `Methods.byId`. Другие встроенные обработчики этим пилотом не утверждаются.
- Контрольные примеры: `tests/fixtures/tki-reference.json`; тесты контракта и формы — `tests/`.
- Научная проверка: `METHOD_VALIDATION.md`; успешный расчет не заменяет статус проверки источника.

## Последующие границы

Участник выбирает вариант по коду, а интерфейс отправляет `{item_id, value}`. Текст вопроса и подпись а/б не участвуют в подсчете баллов. Версии текста формы, ключа и вычислителя фиксируются раздельно.

Исследования, произвольные группы, этапы T0/T1/T2 и назначения методик относятся к будущему доменному слою. Хранение, права доступа, согласия и выбор серверного стека еще не реализованы. Развертывание сайта и способ интеграции форм этим пилотом не определяются.

## Ограничения

Контракт поддерживает одну методику и только исправленный ключ 1.0.0 с обработчиком `tki-contract-0.3.0`. Ключ 1.0.0 проверен, допустимые полностью заполненные сырые результаты имеют `usable_for_aggregation: true`. Запросы с удаленной или неизвестной версией отклоняются без баллов. Подмена ключа под прежним ID блокируется проверкой digest. Полное утверждение инструкции и методики учитывается отдельно; формальные JSON Schema для универсального контракта и редактора библиотеки предстоит утвердить отдельно.

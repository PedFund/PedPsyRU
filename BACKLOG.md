|---|---|---|---|
| 00. Аудит локальной программы | Исходники | Реестр и рекомендации в `AUDIT_EXISTING_CORE.md` | Выполнена в локальном проекте; отчет перенесен |
| 01а. Пилот вычислителя Томаса—Килманна | 00 | Контракт по ID вопросов; контрольные расчеты и явное расхождение ключа | Выполнена |
| 01б. Общий бланк и данные формы | Исходный текст от владельца | 30 пар/60 альтернатив, обе грамматические формы, исходные тексты, тесты | Выполнена; методическое утверждение отдельно |
| 01в. Сверка версии и ключа | 01б + научный источник | Решение по 21A, полный ключ, диапазоны 0–12 и контрольные расчеты | Выполнена: только ключ 1.0.0, старый удален; 15 тестов проходят |
| 01г. Браузерное предъявление одной формы | 01б + 01в | Один вопрос на слайде; выбор A/B, проверка полноты, структурированные ответы | Выполнена: локальный стенд; 31 тест и браузерная проверка |
| 01д. Сохранение прохождения | Выбор стека + модель доступа | Ответы и версия формы сохраняются, повторный вход возвращает прежнюю запись | В работе: схема/учебная база готовы, web-сохранение впереди |
| 01д.1. Схема и права | 01г + мастер-задание | Отношения/ограничения, матрица ролей, контракт сохранения и приемка | Выполнен проект: DATA_MODEL, ACCESS_POLICY, STORAGE_CONTRACT; права/API еще не реализованы |
| 01д.2. Среда и тренировочная база | 01д.1 | Подтвержден движок/драйвер; миграции повторяемы; только синтетический seed; FK/уникальности проверены | Выполнена: SQLite, 22 теста хранения / 53 всего; без web/auth |
| 01д.3. Индивидуальный доступ и изоляция | 01д.2 | Повторный вход в ту же запись; чужие ID/роли/отозванные сессии не открывают ответы | Ожидает |
| 01д.4. Черновик и текущий слайд | 01д.2 + 01д.3 | Подтвержденные ответы/слайд восстанавливаются; ревизии защищают две вкладки; UI показывает состояние записи | Ожидает |
| 01е. Выдача проверенного результата | 01в + 01д | Пять шкал считаются и сохраняются воспроизводимо | Ожидает |

Следующий шаг — 01д.3: индивидуальный доступ и отрицательные проверки изоляции, без публичного доступа. Затем 01д.4 — черновик/слайд; защищенные API не открываются раньше проверки доступа. 01е отдельно проверяет атомарный result и повторное завершение без дубликата. Демонстрация — только вымышленные данные; реальные участники требуют проверки доступа и согласий.

Следующие крупные блоки будут разложены на самостоятельные задачи после завершения пилота; инфраструктура не создается целиком одной задачей.

Технические шаги **01а–01е**, включая **01д.4**, находятся в main после единственного разрешенного объединения [PR #7](https://github.com/PedFund/PedPsyRU/pull/7). Итоговое дерево точно сверено, 134 теста повторно прошли после merge. #1 автоматически отмечен GitHub merged, #2–#6 закрыты как замененные #7; ветки/история сохранены. Следующие функциональные ветки начинаются от актуальной main, не от промежуточной цепочки. Только вымышленные данные; реальный контур/production требуют отдельных утверждений. Следующая фаза по ROADMAP — 2 (производственная архитектура), не немедленное развертывание. Отчет — INTEGRATION_VALIDATION.md.

Следующие продуктовые блоки выполняются по фазам ROADMAP после технической основы:

- Фаза 3: приглашения/блокировка исследователей обеими административными ролями, административная MFA, назначение staff-ролей только суперадмином; глобальное чтение/скачивание результатов обеими ролями. Исследователь не получает индивидуальные ответы/баллы.
- Библиотека/редактор методик только для суперадминистратора: новая версия, проверка обработчика, журнал METHOD_VALIDATION; администратор не дополняет методики и не занимается обработкой.
- При вводе обработки/аналитики: задания, сигналы суперадмину, ручная помощь с причиной/историей, кабинет и нейтральный email. Каждый endpoint — отдельная задача с положительными/отрицательными тестами; не включать весь manager-контур в одну задачу 02в.

Текущая модель заканчивает подготовку 02а–02б и останавливается по указанию владельца. После смены модели технические задачи и проверенные merge разрешены автономно в согласованных пределах; повторное подтверждение каждого шага не требуется. Новые права/методики, оплата и публикация согласуются отдельно.

Следующие крупные блоки будут разложены на самостоятельные задачи после завершения пилота; инфраструктура не создается целиком одной задачей.

Технические шаги **01д.4 и 01е** реализованы и проверены в рабочей ветке; в main не интегрированы. Далее — интеграционная приемка общего дерева с разрешением владельца на merge, без автоматического объединения всех PR. Только вымышленные данные; реальный контур/production требуют отдельных утверждений.
Проверенная реализация 01д.4 опубликована в [PR #7](https://github.com/PedFund/PedPsyRU/pull/7); в main пока только инструкции/дорожная карта, не код пилота. AGENTS.md разрешает автономные технические подзадачи в рамках этапа, но merge требует отдельного разрешения.

Отдельные следующие manager-блоки (после пилота, порядок утверждается отдельно):

- Управление исследователями для обеих административных ролей: список, состояние доступа, безопасный отзыв; без доступа исследователя к первичным ответам.
- Библиотека/редактор методик только для суперадминистратора: новая версия, проверка обработчика, журнал METHOD_VALIDATION; администратор не дополняет методики и не занимается обработкой.

Следующие крупные блоки будут разложены на самостоятельные задачи после завершения пилота; инфраструктура не создается целиком одной задачей.

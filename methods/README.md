# Библиотека методик МетодТест

Материалы проходят отдельные проверки: исходный источник → закрепленный пакет → серверный допуск выпуска. Содержательное утверждение и право распространения учитываются отдельно. Наличие текста, успешный расчет и запись в каталоге не заменяют друг друга.

Не создавайте повторные Markdown-списки выпусков, шкал и источников. Точные идентификаторы и версии берутся из существующих пакетов и манифестов. Эти источники описывают разные уровни готовности; один общий счетчик их не заменяет.

## Утвержденное содержание и техническое состояние

Владелец содержательно утвердил MAIA-R, STAI, FFMQ-39, DAR-R, ШПАНА, ECV-15, пробу Генчи и WHO-5. Каноническое решение – [спецификация восьми методик](../docs/APPROVED_EIGHT_METHODS_SPEC_2026-11-23.md) и [Issue #210](https://github.com/PedFund/PedPsyRU/issues/210). Повторно запрашивать утверждение согласованных формулировок, шкал, ключей и норм нельзя. При недоступности полного утвержденного источника блокируется конкретный технический выпуск; похожая адаптация его не заменяет.

Фактическую проверку файлов и пакетов выполняет:

```sh
node scripts/approved-v1-status.js
```

Команда не проверяет состав рабочей БД, установленный SHA, онлайн-доступность или право распространения. Назначение определяется действующим серверным реестром, установленными миграциями и разрешениями. Старые NOT STARTED/IN REVIEW из отчетов не являются текущим статусом выпуска. Открытые вопросы – в [AGENTS.md](../AGENTS.md) и [Issues](https://github.com/PedFund/PedPsyRU/issues).

## Происхождение и ограничения

ТКИ: [Кардашина С.В., Шаньгина Н.В., 2016](https://pedobrazovanie.ru/images/JOURNAL/archive2016/2016-11-5q8c/36.pdf), таблицы 2–6, страницы 219–220. [form.json](tki/form.json) сохраняет владельческий текст и `source_text`; [ключ 1.0.0](tki/keys/1.0.0.json) – первичную ссылку, таблицы 2–6, страницы 219–220 и решение 21A/21B. Историческая проверка использовала извлеченный текст PDF, без завершенной визуальной сверки. Ошибочный прежний ключ не восстанавливается и не используется как fallback. Проверка расчетного ключа не утверждает полную инструкцию или нормативы.

Карпов: [form.json](karpov/form.json) сохраняет публикацию 2003 года, владельческий текст и восемь разрешенных правок рода: вопросы 11/26 и шесть подписей ответов. Первичная статья при историческом обращении вернула HTTP 403; ограничение сохранено в `provenance`. Перенос ключа из legacy и regression-векторы не являются независимой научной проверкой. Исторические версии и ограничения пакета сохраняются.

Прочие ограничения переноса: не смешивать адаптации MAAS; не достраивать отсутствующие ключи Лахвич/PSS; реконструкция Лахвич не является подтвержденным бланком. Противоречия FACES III, семейного долголетия и ветвления НТН/ВГРК требуют проверки конкретной редакции. Наличие материала не дает права публикации. Действующее отдельное решение имеет приоритет над старым статусом архива.

Кодирование СЖО: шаблон `3 / 2 / 1 / 0 / 1 / 2 / 3` содержит семь позиций, хотя цифровых обозначений четыре. Направления 1–7 или 7–1 берутся из закрепленного ключа. Подтвержденные уточнения [УСК](validation/usk-confirmed.md), [PSI](validation/psi-eight-scales-confirmed.md) и полный источник [УВЛК](validation/psytests-source/01_uvlk_shipilov.md) сохраняются отдельно.

## Стандарт подключения следующей методики

Для расширения библиотеки не требуется универсальный визуальный конструктор: суперадминистратор может организовать внесение отдельного пакета **через код**. Основная цель – не изменять общие компоненты исследований, групп, этапов, участников и прежние результаты для каждой новой методики. Полный обязательный порядок и границы – в [`skills/method-intake-SKILL.md`](skills/method-intake-SKILL.md).

- Зафиксировать точную авторскую версию/адаптацию, паспорт, бланк и инструкцию, варианты ответа, ключ/формулы/реверсы, показатели, нормы либо их отсутствие, источники и правовые ограничения.
- Выбрать готовый адаптер или отдельный доверенный модуль по [METHOD_EXTENSION_CONTRACT.md](../METHOD_EXTENSION_CONTRACT.md). Не исполнять архивный JS и код из пользовательских JSON.
- Зафиксировать неизменяемую версию и контрольные векторы. Независимо проверить показатели и негативные сценарии, затем допуск через серверный реестр.
- Проверить сквозное использование: каталог, назначение по группе/этапу, прохождение, сохранение/возобновление, расчет, результат, доступные проекции и экспорт. Для нестандартных форм отдельные экран/HTTP/хранение могут требовать реализации.
- Раздельно подтвердить техническую, научную и правовую готовность. Исторические формы, ключи и результаты не переписывать.

Текущий раздел суперадминистратора «Перенос методик» показывает состояние библиотеки. Он **не предоставляет** универсальную загрузку и публикацию нового исполняемого модуля.

## Обязательные правила сохранности

- Не восстанавливать методику заново, если ее материалы уже есть в репозитории.
- Не заменять закрепленный ключ похожим ключом другой адаптации или версии.
- Не изменять порядок вопросов, варианты ответов, шкалы, реверсивные пункты, нормативы и интерпретации без методологической проверки.
- Не изменять исторические версии форм, ответы и результаты участников.
- Не считать архивную методику автоматически доступной для прохождения.
- Не считать технически работающий обработчик научно утвержденным.
- Не удалять исходные файлы и манифесты без проверки ссылок и контрольных сумм.
- Не исполнять произвольный код из импортированных архивных материалов.
- Не переносить строки респондентов, персональные данные, локальные базы и секреты вместе с библиотекой.

# Q-LES-Q, 36 пунктов (Н. Е. Водопьянова)

**Версия:** `qlesq_36_vodopyanova@1.0.0-draft`. **Статус:** учебный `draft`, без разрешения на научное и публичное использование.

## Включено в репозиторий

- `source/1.0.0.json`: проверенная исходная редакция 36 пунктов, два словесных полюса и библиография
- `form-local.json`: цифровой бланк, одиночный выбор 1–10 с полюсами для каждого пункта
- `keys/1.0.0-draft.json`: 9 субшкал по 4 пункта, обратные 21, 28, 33, 35
- `core/qlesq-contract.js`: серверный расчет, проверка 36 ответов, классификация и процентный индекс
- `storage/qlesq-release.js`: проверяемый закрепленный выпуск формы и ключа
- `storage/postgres/048_qlesq_36_release.sql`: добавочная миграция технических ограничений для закреплённого выпуска (36 пунктов, варианты 1–10); рабочие исследования и прежние выпуски не переписывает
- `scripts/import-qlesq-local.js`: импорт только при явном запуске для синтетической PostgreSQL; без автоматической миграции реальных данных
- `tests/qlesq-contract.test.js` и `tests/postgres-qlesq-*.integration.js`: арифметика, бланк и полный путь прохождения

## Выходные показатели

Каждая субшкала: 4–40 баллов, общая сумма: 36–360, интегральный индекс: среднее 9 субшкал (4–40), нормированный процент.
Уровни интегрального индекса: 4–10 очень низкий, 11–20 низкий, 21–29 средний, 30–40 высокий. Для дробных значений используется техническое непрерывное правило: <11, <21, <30, иначе высокий. Не использовать его как независимо валидизированные нормативы.

Правила отрицательных вопросов: 21, 28, 33, 35. Преобразование `11 - raw_answer`.

## Приемка

Полный бланк соответствует согласованному источнику; пункт 28: «Очень часто» = 1, «Никогда» = 10.
После разрешённого импорта выпуск доступен в каталоге и назначениях. Участник может сохранить и продолжить черновик, завершить 36 пунктов и получить только публичную проекцию показателей и уровня; ключ и внутренний расчётный payload не выдаются. Кабинет исследователя по-прежнему не раскрывает первичные ответы и индивидуальные баллы.
Наличие выпуска в Git не означает, что он автоматически добавлен в рабочую БД или опубликован. Импорт требует изолированного тестового контура, подтвержденных ролей и отдельной эксплуатации. Права распространения опросника и научное утверждение проверяются отдельно.

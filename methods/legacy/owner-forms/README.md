# Бланки из таблиц владельца

Файл `recovered-headers.json` содержит отдельные черновые формы, извлечённые исключительно из первой строки 17 исходных XLSX в пользовательской папке PedPsiProcessor/Data. Содержимое строк участников, ответы, контакты и исходные таблицы не копировались. Дубликаты форм по совпадению содержимого объединены. Для каждого бланка сохранены название исходного XLSX, индекс листа, номера пунктов, возможный текст вариантов ответа и SHA-256 от массива пунктов.

13 форм содержат последовательные номера с 1 до заявленного количества. Это не подтверждение корректного соответствия ключу: значения шкал, варианты и направление кодирования требуют отдельной сверки, а отдельные формы включают разные варианты для родителей и семей без детей. Записи являются исходными материалами, не назначаемыми выпусками. Для двух методик из исходной библиотеки отсутствует ключ; MAAS отложена по указанию владельца.

ЦО-36 не включена автоматически: её заголовки начинаются с общей инструкции, а не номера пункта. Необходимо отдельно сверить порядок ценностей и особые ограничения на распределение оценок. Порядок или ключ не угадываются. Просмотр каталога и существующие прохождения ТКИ/Карпова не изменены.

Нормализация ответа: для восходящего пункта позиции слева направо получают 1–7; для нисходящего – 7–1. Ноль в центре исходного бланка является позицией ответа, а не итоговым нулевым баллом. Пересечения субшкал предусмотрены ключом.

Для выгрузки с подписанной шкалой `-3,-2,-1,0,1,2,3` обработчик автоматически переводит исходный ответ в позицию `1–7` по формуле `position = response + 4`. Затем для восходящего пункта используется `position`, для нисходящего – `8 - position`.

Таблица перевода сырых баллов в процентили не предоставлена, поэтому обработчик рассчитывает сырые показатели и z-отклонения относительно подходящей нормативной группы, но не выдает приблизительные процентили.

## Направление показателей

Пять субшкал и общая осмысленность жизни: **чем выше, тем лучше**. Z-показатели показывают отклонение от нормативного среднего и не являются отдельными содержательными шкалами.

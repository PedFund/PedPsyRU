# ПеПси – единый комплект обработчиков

В каталоге объединены:
- 11 ранее существовавших обработчиков проекта;
- 16 входных форм Танит.

На уровне входных форм это 27 файлов методик. Некоторые формы используют общий алгоритм (ЦО-36 и FFMQ), поэтому число уникальных алгоритмов меньше числа входных форм.

Для статусов Танит см. `tanit_00_FINAL_STATUS.md` в отдельном архиве Танит или `00_LIBRARY_STATUS.md` здесь.

## Танит
14 из 16 форм имеют вычислительно готовые ключи.
Две формы остаются заблокированы отсутствием проверяемого по-пунктового авторского ключа:
1. Мотивация родительства Ю. Ф. Лахвич.
2. PSS Halverson–Duke в адаптации Е. В. Куфтяк.

Их нельзя достраивать по смыслу пунктов без маркировки как исследовательской реконструкции.

# Специальные паспорта № 32–33

## № 32. Опросник выраженности психопатологической симптоматики, SCL-90-R

### Идентификация

| Поле | Значение |
|---|---|
| ID | `scl90r_90` |
| Каноническое название | Опросник выраженности психопатологической симптоматики, SCL-90-R |
| Автор | Leonard R. Derogatis |
| Русскоязычный источник | Тарабрина Н.В. Практикум по психологии посттравматического стресса. СПб.: Питер, 2001 |
| Число пунктов | 90 |
| Ответы | целые значения 0–4 |
| Период | последние семь дней, включая день обследования |
| Статус | `special_handler_ready` |

### Шкалы

| Код | Показатель | Пункты | Формула |
|---|---|---|---|
| SOM | Соматизация | 1, 4, 12, 27, 40, 42, 48, 49, 52, 53, 56, 58 | среднее ответов |
| O-C | Обсессивность–компульсивность | 3, 9, 10, 28, 38, 45, 46, 51, 55, 65 | среднее ответов |
| INT | Межличностная сензитивность | 6, 21, 34, 36, 37, 41, 61, 69, 73 | среднее ответов |
| DEP | Депрессия | 14, 15, 20, 22, 26, 29, 30, 31, 32, 54, 56, 71, 79 | среднее ответов |
| ANX | Тревожность | 2, 17, 23, 33, 39, 57, 72, 78, 80, 86 | среднее ответов |
| HOS | Враждебность | 11, 24, 63, 67, 74, 81 | среднее ответов |
| PHOB | Фобическая тревожность | 13, 25, 47, 50, 70, 75, 82 | среднее ответов |
| PAR | Паранойяльные тенденции | 8, 18, 43, 68, 76, 83 | среднее ответов |
| PSY | Психотизм | 7, 16, 35, 62, 77, 84, 85, 87, 88, 90 | среднее ответов |
| ADD | Дополнительные пункты | 19, 44, 59, 60, 64, 66, 89 | среднее ответов, служебный показатель |

### Глобальные индексы

Пусть `x[i]` – ответ на пункт `i`.

- `TOTAL = sum(x[1..90])`;
- `GSI = TOTAL / 90`;
- `PST = count(x[i] > 0)`;
- `PSDI = TOTAL / PST`, если `PST > 0`;
- `PSDI = null`, если `PST = 0`.

В некоторых русскоязычных источниках `PST` обозначен как `PSI`. В процессоре следует хранить канонический код `PST`, а `PSI` добавить как псевдоним входного столбца.

### Требования к обработчику

1. Проверить наличие ровно 90 ответов и допустимость каждого значения.
2. Рассчитать девять основных шкал с точностью не менее трех знаков после запятой.
3. Рассчитать GSI, PST и PSDI.
4. Не делить на ноль при пустом профиле.
5. Не присваивать клинический диагноз и не создавать уровни без явно выбранной нормативной таблицы.
6. В краткую аналитику включить GSI и PST; девять шкал и PSDI поместить в глубокую аналитику; ADD считать служебным.
7. Добавить регрессионные тесты для нулевого профиля, максимального профиля и смешанного профиля.

### Контрольные примеры

| Вход | Ожидаемый результат |
|---|---|
| все 90 ответов равны 0 | все шкалы 0; GSI 0; PST 0; PSDI `null` |
| все 90 ответов равны 4 | все основные шкалы 4; GSI 4; PST 90; PSDI 4 |

### Ограничение

SCL-90-R распространяется как лицензируемый инструмент Pearson. До включения текста пунктов и нормативных таблиц в распространяемый продукт требуется проверить условия лицензии.

## № 33. Интегративный тест тревожности, ИТТ

### Идентификация

| Поле | Значение |
|---|---|
| ID | `itt_bizyuk_wasserman_iovlev` |
| Каноническое название | Интегративный тест тревожности, ИТТ |
| Авторы | А.П. Бизюк, Л.И. Вассерман, Б.В. Иовлев |
| Источник | Бизюк А.П., Вассерман Л.И., Иовлев Б.В. Применение интегративного теста тревожности. СПб.: НИПНИ им. В.М. Бехтерева, 2003. 23 с. |
| Формы | ситуативная тревога и личностная тревожность |
| Число пунктов | 15 в каждой форме |
| Ответы | целые значения 0–3 |
| Статус | `needs_clean_key` |

### Планируемые выходы

- общий показатель ситуативной тревоги;
- общий показатель личностной тревожности;
- эмоциональный дискомфорт, ЭД;
- астенический компонент, АСТ;
- фобический компонент, ФОБ;
- тревожная оценка перспективы, ОП;
- социальная защита, СЗ;
- сырые показатели;
- стандартизованные значения по релевантной половозрастной нормативной группе.

### Почему обработчик пока нельзя реализовать

Доступная копия руководства содержит визуально поврежденную таблицу диагностических коэффициентов: значения нескольких строк и столбцов сцеплены, поэтому однозначно восстановить веса ответов нельзя. ИТТ использует не простое суммирование, а диагностические коэффициенты и нормативное преобразование. Перенос предположительно восстановленных чисел создал бы скрытую систематическую ошибку.

### Что нужно получить

1. Читаемую таблицу диагностических коэффициентов для обеих форм.
2. Однозначное соответствие коэффициентов пунктам, вариантам ответа и пяти компонентам.
3. Полные половозрастные таблицы перевода в станайны.
4. Правило обработки пропущенных ответов.
5. Контрольные примеры из руководства или эталонные протоколы.

### Требования к будущему обработчику

1. Различать формы ситуативной и личностной тревоги.
2. Валидировать 15 ответов 0–3 для каждой формы.
3. Применять коэффициент именно той формы и компонента, к которым относится пункт.
4. Хранить сырой и стандартизованный результат раздельно.
5. Выбирать нормы только по явно переданным полу и возрасту; при отсутствии демографии возвращать сырой профиль без автоматического уровня.
6. Не подменять ИТТ простой суммой 15 ответов.
7. Иметь регрессионные тесты на эталонных протоколах из первичного руководства.

До получения чистой таблицы статус методики должен оставаться «Нужны материалы», а не «Готова к импорту».

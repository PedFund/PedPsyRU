# Источники и принятые решения

Основой расчетов являются 24 файла ключей, переданные пользователем. Ссылки на конкретный источник ключа записываются также на лист `Сведения` каждого результата.

## Иерархия показателей с 22.07.2026

Эталонный перечень и иерархия показателей для 17 методик заданы файлом `Методики_Показатели_Выверены!!!ПВН__Ссылки.xlsx`.

- Для исследования Каммалой в краткой аналитике используются 55 содержательных показателей утвержденного перечня. В исследованиях других авторов число рассчитывается по фактически загруженным методикам.
- Показатели второго порядка и субшкалы считаются одним уровнем и используются в глубокой аналитике.
- Для методики Лири показатели рассчитываются отдельно для `Я-реального` и `Я-идеального`: два содержательных показателя превращаются в четыре технические строки, а восемь глубоких показателей – в шестнадцать.
- Нормативные преобразования (стены, T-баллы, процентили, уровни) являются формой представления показателя, а не отдельными содержательными показателями.

Все необходимые исполняемые ключи утвержденного перечня подключены. Для Горностая применяются два авторских показателя без искусственной общей суммы. В МЛО-АМ добавлены АС, ПС и ДАН, переименованы ЛАП и ПР, уточнены пункты 75 и 127. Шкала достоверности рассчитывается по 13 ответам `Нет`: 1, 10, 19, 31, 51, 69, 78, 92, 101, 116, 128, 138, 148.

Нормативные преобразования закрыты для УСК, Карпова, САТ и WCQ. По согласованному исследовательскому решению нормы АС, ПС и ДАН для мужчин 20–25 лет используются как основная нормативная таблица для всех респондентов и явно подписываются в выходных данных.

## Дополнительная сверка форматов выгрузки

- УВЛК А.И. Шипилова: значения 1–5 в выгрузке являются позициями вариантов, а не готовыми баллами. Применено преобразование `1→0`, `2→1`, `3→0`, `4→2`, `5→3`: https://dip-psi.ru/psikhologicheskiye-testy/post/test-po-vyyavleniyu-urovnya-vnutrilichnostnoj-konfliktnosti-a-i-shipilov
- Тест жизнестойкости: ответы формы 1–4 преобразуются в опубликованную шкалу 0–3: https://www.aksp.ru/work/activity/nac_strateg/resurs_centr/files/soln_testgizn.pdf
- СПА Роджерса–Даймонд: ответы формы 1–7 преобразуются в опубликованную шкалу 0–6: https://psylab.info/Методика_диагностики_социально-психологической_адаптации_Роджерса_-_Даймонд
- САТ и тест Томаса: из-за групповых и ошибочных заголовков используется позиционное соответствие ответов ключу после проверки ожидаемого числа столбцов.

## Методологические ограничения

- Ключ двух итоговых показателей PSI предоставлен пользователем 14.07.2026.
- Ключ опросника ролевой компетентности П. П. Горностая взят из авторской монографии.
- Для ОСО выводятся сырые показатели, поскольку таблицы накопленных частот не были переданы.
- Для САТ выводятся сырые показатели и T-баллы по профильному листу.
- Для общей интернальности УСК рассчитывается полная шкала стенов 1–10.
- Для рефлексивности диапазон 81–100 переводится в 1 стен.

Неполные и недостоверные протоколы исключаются из основного XLSX и всех последующих расчетов. Они сохраняются только в отдельном журнале исключений внутри общего ZIP.

# ССПМ-2020 – ключ обработки

```yaml
id: sspm_2020_28
items: 28
response: {valid: [1,2,3,4,5]}
reverse_formula: "6 - x"
scales:
  planning: {direct: [8,22], reverse: [1,15]}
  modeling: {direct: [10], reverse: [4,18,24]}
  programming: {direct: [2,16,26], reverse: [11]}
  results_evaluation: {direct: [3,9], reverse: [17,23]}
  flexibility: {direct: [5,12,19,25], reverse: []}
  reliability: {direct: [], reverse: [6,13,20,27]}
  persistence: {direct: [7,14,21,28], reverse: []}
derived:
  general_self_regulation: "sum(all 28 scored items)"
ranges: {each_scale: [4,20], general_self_regulation: [28,140]}
```

Каждый пункт входит ровно в одну шкалу. Сначала реверсировать указанные пункты, затем суммировать. Общий показатель равен сумме семи шкал.

Источник: https://psytests.org/psystate/sspm.html

## Направление показателей

Семь шкал и общий уровень саморегуляции: **чем выше, тем лучше**.

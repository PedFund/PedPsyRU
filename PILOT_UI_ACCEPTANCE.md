## Режимы просмотра

- `npm run start:platform:ui` → `http://127.0.0.1:4175/workspace`: **только интерфейс** без PostgreSQL. Любые API-сценарии возвращают 503; здесь оцениваются внешний вид, надписи и адаптивность, а не успешность действий.
- `npm run start:platform:demo`: **функциональный синтетический** PostgreSQL-контур. Проверять на loopback, с заранее подготовленной изолированной БД, безопасными синтетическими аккаунтами и MFA. Фактический адрес взять из локального запуска. Никаких реальных участников и данных, никакого подключения к рабочей БД/Selectel.
- До проверки способ установки/запуска уточнить, на каком из двух компьютеров проводится просмотр. Уже существующую среду не изменять без проверки.

## Исследователь: дизайн и ход исследования

- [ ] Вход под researcher, вкладки «Мои исследования», создание черновика и открытие исследования.
- [ ] Навигация по разделам «Дизайн исследования», «Сведения об участниках», «Методики» и обратно.
- [ ] Начальная группа «Экспериментальная» и этап T0, добавление контрольной группы, этапов и заметок.
- [ ] Поиск методик, назначение разрешенных выпусков группе и этапу; архивные 50 описаний не равны 50 назначаемым тестам.
- [ ] Добавочные поля анкеты и ограничения, подтвержденное сохранение, активированный дизайн защищен от незаметного изменения.
- [ ] Генерация ссылки-приглашения для группы; секрет не сохраняется в браузере после обновления.
- [ ] «Ход исследования»: регистрации, прохождения, завершения. **Никаких исходных ответов и индивидуальных баллов**.
- [ ] Перезагрузка/выход не теряют подтвержденные сервером настройки; в preview API 503 ожидаем.

## Обработка и статистика: что уже есть и что планируется

- **Есть:** хранение первичных ответов, версия назначенной методики, отдельный серверный расчет результатов ТКИ и Карпова и ограниченное представление результатов.
- **В работе по задачам пилота:** сквозная проверка оставшихся методик, научный и правовой допуск и административная CSV/Excel-выгрузка.
- **Цель до 01.12:** поэтапная статистическая обработка на сервере для researcher по **разрешенным обработанным показателям своего исследования**: описательные статистики, сравнение групп/этапов, затем другие методы и отчетность.
- Текущий `aggregates.read` в политике ролей **не означает**, что готов статистический API/экран. Отсутствие нового модуля при первом просмотре – известная незавершенная функция.
- Уровень доступа исследователя к индивидуальным псевдонимизированным **обработанным** баллам требует отдельного решения владельца; исходные ответы запрещены в любом случае.

## Фиксация результата

Каждый дефект: роль → режим → раздел/URL → шаги воспроизведения → ожидаемое/фактическое → устройство/ширина экрана → обезличенный скриншот. P0: потеря ответов, пересечение ролей или утечка; P1: невозможно пройти сценарий; P2: визуальные недочеты. Ручной просмотр не заменяет CI, реальную PostgreSQL-интеграцию и браузерные E2E на точном SHA. Изменения оформляются отдельными ограниченными PR.

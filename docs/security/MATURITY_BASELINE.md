# Базовая оценка уровня зрелости (У_зи)

Дата: 2026-11-17. База: `main` `2b438f9`. Методика: методический документ ФСТЭК России от 07.08.2026 «Методика оценки уровня зрелости деятельности в области ТЗИ в ИС и обеспечения безопасности значимых объектов КИИ». Связанные документы: [DATA_INVENTORY.md](DATA_INVENTORY.md), [UVZ_DRAFT.md](UVZ_DRAFT.md), [THREAT_MODEL.md](THREAT_MODEL.md).

Статус: **внутренняя самооценка агента** по коду и конфигурации. Это вход для оператора, а не утверждённый отчёт: официальную оценку проводит оператор (внутренняя) или лицензированная организация (внешняя), с подтверждающими документами.

## 1. Как считается

- Уровень зрелости направления `P_зн = Σ(w_j · a_j)` по 8 видам требований.
- `a` — степень выполнения: 0 / 0.5 / 1.
- Веса: документирование 0.15, выполнение 0.20, инструменты 0.10, квалификация 0.10, контроль 0.15, обучение 0.10, внешний аудит 0.10, актуализация 0.10 (сумма 1.00).
- Уровень направления: `P < 0.2` → 0; `0.2 ≤ P < 0.35` → 1; `0.35 ≤ P < 0.65` → 2; `0.65 ≤ P < 0.9` → 3; `P ≥ 0.9` → 4.
- Итоговый `У_зи` — среднее по направлениям.

Ориентир по методике: для операторов ИСПДн 3 уровня защищённости целевой уровень по каждому направлению — **не ниже «1»**. Ниже приведены предложения оператора выше минимума.

## 4. Почему оценки именно такие

- **Документирование 0.5 везде**: живые документы (AGENTS, CURRENT_STATE, SECURITY_AND_DEPENDENCIES, docs/security) есть, но нет утверждённых оператором политик, регламентов и приказов по ПДн.
- **Выполнение 1.0** там, где мера реализована в коде и проверяется тестами; 0.5 для обновлений (цикл ручной) и 0 для инцидентов (процесса нет).
- **Инструменты 1.0** для доступа/уязвимостей/SSDLC (RLS, CI-гейты); 0.5 там, где защита есть, но без специализированных средств (нет SIEM, WAF, автоматического backup).
- **Квалификация 0.5**: работа идёт, но нет подтверждённых сертификатов/программы обучения.
- **Контроль 0.5**: есть автотесты и аудит, нет регулярных проверок и пересмотра доступов; для инцидентов контроля нет вовсе.
- **Обучение, внешний аудит — 0**: программы обучения и независимой оценки нет.
- **Актуализация 0.5**: изменения вносятся по мере задач, планового цикла пересмотра мер нет.

## 6. Ограничения

- Оценка сделана по коду и конфигурации стенда, без опроса сотрудников и без проверки документов оператора.
- Баллы «документирование», «квалификация», «обучение» и «внешний аудит» отражают отсутствие подтверждённых артефактов, а не качество людей.
- Итоговый отчёт по методике требует подписи специалистов и утверждения руководителем; этот файл — черновик для такой работы.

# Модель угроз МетодТест

Дата: 2026-11-17. База: `main` `2b438f9`. Связанные документы: [DATA_INVENTORY.md](DATA_INVENTORY.md), [UVZ_DRAFT.md](UVZ_DRAFT.md), [MATURITY_BASELINE.md](MATURITY_BASELINE.md).

Статус: рабочая модель для инженерных решений и подготовки оценки У_зи. **Не заменяет** модель угроз по методическим документам ФСТЭК и не является утверждённым оператором документом.

## 1. Что защищаем

- ПДн участников: email (логин), пол, возраст, город, организация, образование, ответы и результаты методик, факты согласий.
- Учётные записи исследователей и staff: логин, хэш пароля, сессии, MFA-факторы.
- Целостность исследования: дизайн, назначения, неизменяемая история анкет и результатов, аудит.
- Доступность сервиса и почтового контура подтверждений.
- Секреты: ключи MFA/контактов, SMTP-пароль, доступ к БД и инфраструктуре.

## 2. Архитектура и точки доверия

| Компонент | Роль | Границы |
|---|---|---|
| nginx 1.28.3 | TLS-терминация, статика, прокси на 127.0.0.1:4174 | сертификат Let's Encrypt до 2027-02-14; CSP и `X-Content-Type-Options` включены; **HSTS отсутствует** |
| Node/TypeScript (Fastify) | HTTP/API, сессии, права, аудит | `Fastify({logger:false})` – журнала запросов нет |
| PostgreSQL 18 | данные, RLS, SECURITY DEFINER | runtime-роль без прав на таблицы ПДн; функции принадлежат владельцу схемы |
| Outbox-воркер | письма подтверждения | Selectel SMTP, лимит 100/5 мин, TTL 24 ч |
| GitHub Actions | CI: тесты, PG, браузер, audit, secret scan | действия закреплены по SHA; `npm ci --ignore-scripts` |
| Backups | `pg_dump -Fc` в `/var/backups/mettest` | 600 root, без шифрования и авто-ротации |

## 3. Нарушители

1. Внешний атакующий без учётной записи (подбор, эксплуатация веб-уязвимостей, DoS).
2. Участник (легитимный, но любопытный/недобросовестный): чужой этап, чужие данные, повторное прохождение.
3. Исследователь: доступ к своим исследованиям, попытки выйти за скоуп.
4. Staff/администратор: широкие права, MFA, риск ошибки.
5. Инсайдер эксплуатации: root на сервере, доступ к БД, backups, секретам.
6. Подрядчик: Selectel (хостинг, БД, SMTP), разработчик.
7. Supply chain: npm-зависимости, GitHub Actions, образы.

## 4. Угрозы, меры и остаточный риск

Приоритеты: **P1** — до реального пилота; **P2** — в квартале; **P3** — планово.

| ID | Сценарий | Существующие меры (доказательство) | Остаточный риск | Приоритет |
|---|---|---|---|---|
| Т-01 | Подбор пароля участника | scrypt (64 байта, соль 16 байт), сравнение в постоянном времени и dummy-соль (`storage/access.js`, `identity.ts`); троттлинг per-code/email 5/15 мин и глобальный лимит (`007`, `087`); сессия 30 мин, простой 10 мин (`004:41`, `002:68`) | нет второго фактора у участника; лимит общий на процесс | P2 |
| Т-02 | Угон cookie/сессии | `__Host-pedpsy` + `Secure; HttpOnly; SameSite=Strict` (`participant-app.ts:58-62`); CSP `default-src 'none'; frame-ancestors 'none'`; токены не в localStorage; старый токен отзывается при входе (`004:39`) | нет привязки сессии к устройству; XSS на своей странице остаётся критичным | P2 |
| Т-03 | Чужой участник/чужое исследование (IDOR) | RLS на 39 таблицах; доступ только через SECURITY DEFINER с фиксированным `search_path`; проверки владельца в SQL; тесты «чужой участник/чужое исследование» | возможны пропуски в новых эндпоинтах | P2 |
| Т-04 | Эскалация роли (участник→исследователь→staff) | роли в БД, MFA staff, аудит, запрет impersonation; staff-функции не выданы runtime-роли целиком | ошибки в новых admin-функциях | P2 |
| Т-05 | Подмена/перехват кода подтверждения | TLS; код в зашифрованном конверте (`token_envelope`); TTL 24 ч; привязка к браузеру; одноразовость; rate limit почты 100/5 мин | почта как канал остаётся слабым звеном; нет подписи писем | P2 |
| Т-06 | Утечка ПДн через API/экран | progress DTO без email (#144); `display_code` вместо email в экспорте; аудит без email/кодов; тесты «нет `@`» | остальные проекции не проверялись сплошным образом | P1 |
| Т-07 | SQL-инъекция/инъекция в функции | параметризованные запросы; нет динамического SQL в проверенных путях; фиксированный `search_path`; RLS | ревизия всех SQL-функций не завершена | P2 |
| Т-08 | Компрометация зависимости или CI | lockfile, `npm ci --ignore-scripts`, `npm audit` как гейт, gitleaks по истории, действия по SHA, `dependency-policy.json` | нет SBOM и SAST; обновления вручную | P1 |
| Т-09 | Утечка секретов | `.env` вне Git, 640 `root:mettest`; secret scan; аудит без ПДн; `logger:false` | секреты в памяти процесса и в окружении; ротация не регламентирована | P2 |
| Т-10 | Несовершеннолетний участник | миграция 091: допуск требует возраст 18+, иначе 403; значение <18 не сохраняется; тесты `postgres-admission-age` | регистрация возраст не собирает; исследование без поля возраста никого не допускает | P1 (закрыто, см. остаток) |
| Т-11 | Потеря/повреждение данных | append-only миграции, immutable-строки, backup перед выпуском, `pg_restore --list`, предпроверка владельцев (PR #145) | полное восстановление не репетировалось; RPO/RTO не утверждены | P1 |
| Т-12 | DoS/брутфорс регистрации и логина | глобальные throttle-бакеты, лимит 1000 pending, лимит почты | нет WAF/лимитов на nginx; нет мониторинга аномалий | P2 |
| Т-13 | Утечка у подрядчика (Selectel) | юридически не оформлено; технически — изолированная runtime-роль | нет DPA и требований к У_зи подрядчика | P1 |
| Т-14 | Инсайдер с root/доступом к БД | отдельные роли БД, аудит приложения | действия суперпользователя не аудируются приложением; нет PAM | P1 |
| Т-15 | Утечка через backup | файлы 600 root | не шифруются, копируются вручную, срок хранения не задан | P2 |
| Т-16 | Тайминг-атака на существование аккаунта | dummy-соль и постоянное время сравнения | — | P3 |
| Т-17 | Фиксация сессии | новый токен при входе, отзыв прежних сессий | — | P3 |

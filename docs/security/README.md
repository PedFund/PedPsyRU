## Ключевые выводы

- Категория ПДн — иные (данные о здоровье не обрабатываются), субъекты не сотрудники, менее 100 000, ГИС/КИИ нет.
- Уровень защищённости — **УЗ-3** (ПП № 1119, п. 11 «б») при угрозах 2-го типа; УЗ-1 возникнет только при признании актуальными НДВ в системном ПО.
- Требуются организационные действия: ответственное должностное лицо (п. 14), перечень лиц с доступом (п. 13 «в»), документы по помещениям, носителям и СЗИ.
- До реальной обработки ПДн нужны реальные тексты согласий/уведомлений: сейчас схема допускает только `synthetic_only`.
- Базовая зрелость **У_зи = 0.45 (уровень 2)**; направление «реагирование на инциденты» — **0** при минимуме «1» для ИСПДн 3 УЗ. Это первый разрыв для закрытия.

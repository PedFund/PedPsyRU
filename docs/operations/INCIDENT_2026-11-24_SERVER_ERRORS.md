## Причина 1 — statement timeout при завершении попытки

PostgreSQL:

```
ERROR: canceling statement due to statement timeout
STATEMENT: UPDATE pedpsy.attempts SET status='completed', ...
CONTEXT: PL/pgSQL function guard_attempt() line 9 at IF
```

`guard_attempt()` считал `responses` **под ролью участника**, то есть через RLS и цепочку `current_admission_allows`. На ECV-15 подсчёт выходил за `statement_timeout = 5000 ms`; транзакция откатывалась, HTTP отдавал 503 `STORAGE_BUSY`.

Исправление: PR #236 — `guard_attempt()` переведён в `SECURITY DEFINER`; служебная проверка целостности выполняется владельцем, без RLS. Правило «15 ответов для ECV-15» не изменено.

## Причина 2 — 404 на уже завершённые результаты

`result` возвращал 404, потому что `can_read_attempt` разрешал чтение только при **действующем** допуске этапа. После изменения/закрытия этапа завершённая попытка переставала читаться.

Исправление: PR #242 — владелец всегда читает свою **завершённую** попытку; активные попытки по-прежнему требуют действующего допуска.

## Причина 3 — повторные дорогие чтения

Страница этапа последовательно запрашивала `/attempts/:id/form` для каждой методики. При 5 методиках это 5 отдельных RLS-запросов; p95 одного — 6 с. Добавлено:

- один повтор чтения формы/черновика при кратком `STORAGE_BUSY` (PR #235);
- параллельная загрузка форм этапа (этот PR) — суммарное время страницы определяется самым медленным запросом, а не суммой.

## Ограничения

- Нет `pg_stat_statements`: нельзя доказать вклад отдельных SQL по всему времени.
- Нет изолированного нагрузочного стенда с синтетическими данными; сравнение p50/p95 ограничено журналом.
- 404/403 unmatched — внешние сканеры; к API не относятся.
- 1 × nginx 502 совпал с ручным перезапуском приложения, не с дефектом кода.

## Остающиеся гипотезы

1. Стоимость `current_admission_allows` внутри RLS на каждом `release_items`; нужен замер на синтетическом контуре после включения `pg_stat_statements`.
2. Возможная польза кэша неизменяемых форм выпуска на процесс; требует проверки прав и инвалидности.
3. Таймауты 5 с могут быть тесны для пилота 200 участников; повышать только после нагрузочного теста.

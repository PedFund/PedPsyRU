## Правила каждого этапа

1. Проверить форму, ключ, контрольные векторы, названия, отображение, результаты и экспорт.
2. Изменение содержимого закрепленной формы или ключа требует **новой версии**; существующие digest, история и ответы не меняются.
3. Рабочая PostgreSQL и Selectel не участвуют; интеграционные тесты только на синтетических данных.
4. После каждого ограниченного PR фиксировать SHA, CI, результаты проверок и незавершенные вопросы.
5. Сначала закрыть методическую подготовку, затем возвращаться к отдельному PR #208 по дизайну.
6. Зеленый CI подтверждает инженерные проверки, но не научную валидность или права на распространение.

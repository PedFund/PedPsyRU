# Журнал решений

## 2026-10-02 — вход участника 01д.3а и уточнение административных прав

Реализован локальный вход участника: scrypt N=131072/r=8/p=1, salted hash, серверные token hashes, сроки 30/10 минут, same-origin/CSRF logout, сохраняемые login лимиты, метаданный аудит, scoped чтение своих попыток. Локальная выдача/сброс/отзыв только интерактивной CLI, без автоаккаунтов/паролей. В браузере отдельный /access со статусами; сохранение формы не подключено. Полные границы и 76 успешных тестов — ACCESS_VALIDATION.md.

Владелец прямо уточнил: **админ и суперадмин могут видеть и скачивать первичные ответы**. Прежнее решение «административная роль не дает такого права без специального разрешения» ниже — историческое и **заменено этим уточнением**. Для обеих подтвержденных ролей это штатное право; просмотр/экспорт аудируются, credentials не выдаются, чужой протокол не редактируется. Исследователь по умолчанию не получает ответы. Точный охват исследований ролей пока не утвержден; не подменять его неявным безграничным доступом. Добавлен отдельный 01д.3б до 01д.4: роли/область, просмотр, защищенное скачивание и tests. В текущем runtime administrative credentials/API не созданы.

## 2026-10-02 — тренировочная база 01д.2

Проверены Node.js 22.17.1 и SQLite 3.50.0. Для локального demo выбран экспериментальный встроенный node:sqlite / DatabaseSync, без установок/внешних пакетов. Предупреждение не скрывается, production-стек не утверждается. .local/training.sqlite не публикуется в Git и не подключается к неавторизованному web-серверу.

Реализованы 13 отношений и метаданные миграций/seed, STRICT/CHECK/составные FK, неизменяемость выпуска/завершенного протокола и отложенные взаимные связи result/completed. Attempts дополнены group_id/stage_id и completion_result_id; результат — attempt_status. Recursive triggers включены против обхода REPLACE. Ограничения не заменяют серверное вычисление/права/CAS/идемпотентность: сервис завершения остается 01е, test-only SQL лишь проверяет схему.

Seed — два вымышленных исследования, КГ/ЭГ и T0–T2, без credentials/сессий. Повтор не перезаписывает ответы. TKI импортируется из существующих JSON, только ключ 1.0.0. Form_digest — SHA-256 canonical-json-v1 всего JSON; key_digest — прежняя канонизация вычислителя. Responses_digest упорядочивает выбранные item_id/value по выпуску, не подставляет пропуски. Детали — storage/README.md.

Дальше отдельно 01д.3: индивидуальный доступ/отрицательные проверки изоляции; затем 01д.4 — черновик/слайд браузера. Реальные данные и публичное размещение не разрешаются этим шагом.

## 2026-10-02 — схема тренировочной базы и доступа 01д.1

По согласованному шагу подготовлены DATA_MODEL.md, ACCESS_POLICY.md и STORAGE_CONTRACT.md. Схема отделяет пользователя от участника исследования, назначение группа–этап–выпуск от попытки и фиксирует одну попытку назначения в первом контуре. Слайд сохраняется по item_id, не по тексту. Черновик записывается атомарным снимком с expected_revision; конфликт двух вкладок не разрешается молчаливой перезаписью. Повторное завершение возвращает тот же результат.

Исследователь по умолчанию получает статусы и только разрешенные агрегаты, не индивидуальные ответы/баллы. Административное ограничение этого первоначального проекта впоследствии отменено владельцем: актуальное право просмотра/скачивания обоих административных уровней описано в решении 01д.3а выше. Порог защиты малых групп и grants для иных получателей остаются отдельными решениями. Реальные данные, юридические тексты и публичное размещение не включаются.

Модель здесь является техническим проектом для будущей реализации: базы, миграций и сессий еще нет. Движок/драйвер выбираются после проверки среды; предпочтения мастер-задания учитываются, но не выдаются за уже развернутый стек. Существующий JS-расчет не переписывается. Перед закрытием можно гарантировать восстановление только сервером подтвержденных ответов. Дополнительные ретесты/пересчет completed требуют отдельного решения.

## 2026-10-02 — один вопрос на отдельном слайде

По обязательному требованию владельца каждая пара TKI предъявляется отдельно; это правило действует и для будущих форм: один вопрос — один слайд. Реализованы «Назад»/«Далее», счетчик текущего вопроса, сохранение выбора при переходах и открытие нужного слайда по ссылке на пропуск. Навигация допускает пропуск вопроса, но неполный протокол не рассчитывается. Проверка — на последнем слайде. «Ваш прогресс» показывает число заполненных пар, не номер слайда.

Исправлен заголовок «Поведение в конфликте»: обычные пробелы вместо разрыва строки без пробела. Подпись «Общий бланк для мужчин и женщин» удалена из интерфейса, название теста сохранено. Исходные тексты вариантов и ключ не изменены.

## 2026-10-02 — браузерный стенд 01г

Согласован небольшой локальный стенд одной методики. Используется установленный Node.js и стандартный `http`, без внешних пакетов; UI — HTML/CSS/JavaScript. Это транспорт для существующего JS-вычислителя, не выбор стека всей платформы и не переписывание формул ради другого языка. JSON остается источником текстов. Дизайн — бирюзово-голубой, форма адаптивная.

Стенд доступен только на loopback, явно демонстрационный, без сохранения ответов, базы, авторизации и публичного размещения. Используются только вымышленные ответы. Просмотр сырых баллов — проверка связи формы с обработчиком, без нормативов и психологических заключений. Хранение, модель доступа и повторный вход — следующий отдельный шаг.
